# AppleMusic_BPM

A personal Python project for Apple Music library metadata extraction, BPM analysis, and music classification.

## Features

- Apple Music library metadata extraction
- BPM and musical key lookup
- Local caching and data analysis
- Excel and CSV export

## Data Source

BPM and musical key data are provided by [GetSongBPM](https://getsongbpm.com/).

This project is intended for personal and non-commercial use.
